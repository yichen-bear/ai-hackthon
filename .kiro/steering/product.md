# Product Overview

AI Hackathon project — a full-stack web application built for a hackathon competition.

- **Frontend**: User-facing web UI served via Nuxt 4 (Vue 3)
- **Backend**: REST API built with Express.js, backed by a PostgreSQL database managed through Prisma ORM
- **Language**: The team primarily communicates in Traditional Chinese (zh-TW); comments and docs may be in Chinese

The project is in early-stage development with scaffolding in place but minimal business logic implemented yet.
